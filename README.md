## ⚡ The Architecture: "Verified Workflows"

Every script in this gallery is:
1.  **Verified:** Tested on the UCR Research Computing Cluster.
2.  **Standardized:** Uses best-practice `#SBATCH` directives for resource efficiency.
3.  **Modular:** Designed to be a "template" for researchers to adapt.

### Example Workflow: AlphaFold (CNAS)
```bash
#!/bin/bash
#SBATCH --job-name=AlphaFold
#SBATCH --partition=gpu
#SBATCH --gres=gpu:a100:1
#SBATCH --time=24:00:00

module load alphafold/2.3.1
run_alphafold --fasta_paths=input.fasta --output_dir=results/
```

## 🤖 Automated Generation

This gallery is not manually maintained. It is **Automated Infrastructure**.

The entire repository (README, Index, and HTML Gallery) is generated by a custom Python engine (`src/gallery`) that scans the raw script directory, parses the Slurm headers, and builds the documentation artifacts dynamically.

**Tech Stack:**
*   **Python 3.12+**
*   **Jinja2** (Templating)
*   **Slurm** (Workload Manager)
*   **uv** (Package Management)
